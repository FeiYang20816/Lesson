# 课序 Lesson

课序是一款用于管理个人课表和待办事项的 Android 应用。支持按周查看课程、临时调课、待办提醒和自定义背景，无需注册账号，数据保存在设备本地。

支持 Android 8.0 及以上版本。

## 安装

前往 [Releases](https://github.com/FeiYang20816/Lesson/releases) 下载 APK，传到手机后打开安装。当前版本为预览版；升级或卸载前，建议在应用中导出备份。

## 开始使用

1. 在“我的 → 导入课表”选择学校导出的 `.xls` 或 CSV，核对预览后确认导入。
2. 在“我的 → 学期与节次”设置**第 1 周星期一的日期**，课表会据此显示每一周的实际日期。
3. 如需课程提醒，填写对应节次的开始时间，再开启“课程提醒”。具体时刻可以在课表上保持隐藏。
4. 在“待办”中添加事项，按需分别设置截止时间和提醒时间；在“我的”中开启“待办提醒”。

更多操作见 [使用指南](docs/手机试用步骤.md)。

## 功能

- **课表**：按周查看和全学期总览；显示课程名称、教室和节次；同名课程使用相同颜色。
- **课程调整**：新增课程、修改单次或整条重复安排、取消课程；查看修改前后内容并恢复原安排。
- **待办**：新增、编辑、勾选完成、归档，以及恢复未完成。
- **提醒**：课程和待办分别设有总开关，单条课程可独立关闭提醒；显示系统通知与精确提醒权限状态。
- **背景**：为课表、待办和“我的”分别选择图片，调整遮罩或恢复默认背景。
- **本地备份**：导出和恢复课表、待办、设置、修改记录及背景图片。

“修改全部周次”只作用于选中的这一条重复上课安排。例如同名课程周一和周二各上一次，修改周一的安排不会同时修改周二。

“恢复原安排”以最近一次确认导入的课表为基准。整体恢复会移除人工新增和调整，保留待办、设置及历史记录；操作前会提示影响范围。

## 导入格式

支持 BIFF8 `.xls`、课表网格 CSV，以及 [CSV 列表模板](docs/课表导入模板.csv)。不同学校的表格结构可能不同，请在导入预览中核对课程与周次；也可以按模板整理数据。

CSV 支持 UTF-8、GB18030 和 UTF-16，支持带引号、逗号和换行的字段。周次可写为 `1-8,12`、`9,13[周]` 或 `1-18[单周]`。同一格中的多条安排会分别解析；只有周次、没有星期和节次的实习或课程设计保留为备注。

当前不直接读取 `.xlsx`，请另存为 `.xls` 或按模板导出 CSV。无法识别的内容会在预览中提示，确认后才会保存。

## 数据与权限

应用没有网络访问权限，课表和待办保存在本机。背景通过系统照片选择器选择，旧系统回退到文件选择器，只读取选中的图片。备份由使用者主动导出，卸载前请妥善保存。

通知需要系统授权。课程提醒还需要设置开学日期及节次开始时间；未授予精确提醒权限时，通知可能延迟。手机强制停止、省电设置和关机会影响提醒，请在自己的设备上确认。

## 源码与构建

界面使用 Kotlin 和 Jetpack Compose，本地存储使用 Room，提醒使用 AlarmManager 和 WorkManager。构建要求和检查方法见 [开发说明](docs/开发说明.md)，功能规则见 [功能与数据设计](docs/实施方案.md)，测试范围见 [验证记录](docs/验证记录.md)。
