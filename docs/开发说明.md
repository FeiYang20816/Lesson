# 开发说明

## 环境

- JDK 21，字节码目标为 Java 17。
- Android SDK：`platforms;android-35`、`build-tools;35.0.0`、`platform-tools`。
- Gradle Wrapper 8.11.1、Android Gradle Plugin 8.9.2、Kotlin 2.1.20。

使用 Android Studio 打开仓库，配置 Android SDK 后同步。命令行构建时可设置 `ANDROID_HOME`，或在未提交的 `local.properties` 中设置 `sdk.dir`。请使用自己的 SDK 路径。

## 构建与测试

在 Windows PowerShell 中运行：

```powershell
.\gradlew.bat :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

本地 Android 测试使用 Robolectric，首次运行需下载对应运行环境。若 Java 自动下载失败，可运行 `python tools/prepare-local-tests.py` 预缓存并校验运行环境。

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。调试签名仅用于本地构建和预览安装，正式发布时请配置自己的签名，并在升级前核对签名是否兼容。

连接专用测试手机或模拟器后运行：

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

设备测试会替换被测应用的数据，请使用专用测试设备或测试安装环境。

macOS 和 Linux 可使用等价的 `./gradlew` 命令。Windows 可选用 `tools/build.ps1` 运行组合检查；`tools/bootstrap.py` 可下载并校验独立的 Windows 构建工具，SDK 平台及许可仍需自行配置。

## 模块

- `core`：课表解析、周次与日期、课程调整与恢复、提醒计划和备份校验。
- `app`：Compose 页面、本地持久化、照片选择、通知和备份文件读写。
- `docs`：使用指南、CSV 模板、功能规则和验证范围。

Room 原子保存一个版本化状态快照，使课程变更与历史记录一起持久化。

## 示例与隐私

自动测试使用虚构课程。请不要将个人课表、照片、导出的备份、数据库、签名密钥、令牌、SDK 路径或运行日志提交到仓库。默认忽略本地配置、缓存和生成文件；提交前仍应检查暂存区。

命令行导入工具会输出所选文件中的课程安排；如将报告用于公开反馈，请先脱敏。
