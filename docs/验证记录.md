## 测试范围

核心测试覆盖 XLS/CSV 读取、编码与带换行的字段、非法周次提示、跨年与闰日日期、单次移动、整条重复安排修改、恢复原安排、重复导入保留人工修改、时间冲突、课程颜色、独立提醒开关、延迟提醒及备份验证。

本地 Android 测试在 Robolectric API 35、原生图形和 SQLite 模式下执行，覆盖：

1. 从页面新增待办、完成归档、恢复未完成及重新打开数据库。
2. 修改某一周课程的教室，确认其他周未变，再从修改记录恢复。
3. 图片方向校正、内部保存，以及带背景的 ZIP 备份恢复。
4. 生成通知、过滤已完成待办、处理延迟期间到期事项及避免重复发送。

仓库中的测试和 CSV 模板使用虚构数据，不依赖个人课表。

## 设备试用

已收到 Android 手机基础试用反馈，主要功能可使用。该反馈不代表所有设备兼容性或提醒场景均已验证。
