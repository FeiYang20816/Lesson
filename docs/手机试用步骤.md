# 课序 · 使用指南

## 安装和导入

1. 在 [Releases](https://github.com/FeiYang20816/Lesson/releases) 下载 APK，传到 Android 手机后安装。最低支持 Android 8.0。
2. 将学校导出的课表也传到手机。在“我的 → 导入课表”选择文件，核对预览后确认导入。
3. 核对预览中的课程、教室、节次和周次是否与自己的课表一致。实习及课程设计若无星期和节次，会显示在全学期总览的备注中。
4. 在“我的 → 学期与节次”填写真实的**第 1 周星期一日期**，请以学校校历为准。

## 课表与调整

- 点周次选择周；点左右箭头逐周切换。课表网格可上下及左右滑动。
- 点课程查看教室、节次和日期，再点“修改课程”。默认仅改这一次，可改教室、星期、节次及目标周次。
- 选择“此上课安排的全部周次”，会修改这一条重复安排。例如同一课程周一和周二各上一回，修改周一的安排不会连带修改周二。
- 点空白格或右下角加号新增课程。同名课程自动保持同色。
- 在“我的 → 修改记录”查看变更并恢复单条安排；“恢复原安排”可整体恢复最近一次导入的课表。确认窗口会说明影响范围。

## 待办和提醒

1. 在待办页面点加号，填写标题；截止时间与提醒时间可以分别选择，也可以留空。
2. 勾选后进入“已归档”，再次取消勾选即可恢复未完成。
3. 在“我的”分别开启课程提醒、待办提醒，并按系统提示允许通知。
4. 课程提醒需要对应节次的开始时间。具体时刻可以在课表上保持隐藏。
5. 为核对手机提醒，先创建一个几分钟后提醒的待办，锁屏等候；再检查点击通知是否进入待办页面。
6. 手机重启、长时间锁屏和系统省电模式下的提醒，请在自己的手机上分别确认。未允许精确提醒时，系统可能延迟通知。

## 背景和备份

- 在“我的 → 页面背景”分别选择课表、待办、我的页面图片。只需选择所需图片，选中后保存在应用内部。
- 可调整浅色遮罩，也可分别恢复默认背景。
- “导出备份”保存 ZIP 文件，包含课表、待办、修改记录、设置和背景。请把备份保存到手机以外的位置。
- 恢复备份会替换当前数据，界面会先提示备份内容并要求确认。卸载前先导出备份。

## 反馈问题时

记录出现问题的页面、操作步骤、手机型号及 Android 版本；若是提醒问题，同时记录设置的提醒时间、实际到达时间和权限状态。

当前为预览版。应用初次打开没有预装个人课程，也没有预设开学日期；需自行导入和设置。
