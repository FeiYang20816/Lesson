# 功能与数据设计

课序提供课表、待办和“我的”三个页面，采用简约浅色界面，数据保存在设备本地。

## 显示重点

课程卡片优先显示课程名称、教室和节次；教师放在详情中。具体上课时刻默认隐藏，可在设置中开启。不同课程分配不同颜色，同名课程跨周保持同色。

## 课表与日期

导入 XLS 或 CSV 后先展示预览、学期备注及无法识别的内容，确认后保存。支持连续周、不连续周、单双周及同格多条安排。

通过“第 1 周星期一日期＋周次＋星期”计算实际日期。没有明确星期和节次的实习或课程设计作为备注保留。开学日期及节次时间由使用者设置。

## 调整与恢复

导入原始安排、人工新增、整条重复安排修改和单次例外分别保存。单次例外绑定原始周次，因此移到另一周后仍可追溯。

重复导入会先显示新增、变化和移除内容；保留人工新增和调整。无法匹配的调整会提示，允许在修改记录中移除。

修改记录保留调整前后内容，恢复操作也会记入历史。可以恢复一条安排或整个课表；整体恢复以最近一次导入为基准，移除人工新增和调整，保留待办、设置和历史。

## 待办与提醒

待办可以分别设置截止时间和提醒时间，勾选后归档，取消勾选后恢复未完成。

课程与待办分别设置提醒总开关。修改课程、完成待办或删除事项后重新安排提醒；系统重启、时间或权限变化后进行恢复检查。

课程提醒依赖开学日期和节次开始时间；缺失时不生成该节次的提醒。系统延迟触发时，会一起检查延迟期间到期的事项，避免重复通知。

## 背景与备份

三个页面可分别选择背景图片。图片保存为应用内部副本，校正方向并控制尺寸，使用浅色遮罩保证文字可读。

ZIP 备份包含课表、待办、设置、修改记录和背景。恢复前展示内容数量，确认后替换当前数据。
